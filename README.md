# Hackathon Widelab 2026

Materiały i prototypy warsztatu: Astro, praca z AI i design system Widehue.

## Aktualny przewodnik

`hackathon-guide/index.html` — przewodnik uczestnika z etapami, zadaniami, promptami do kopiowania, inspiracjami i lokalnym zapisem postępu.

Uruchomienie z katalogu repozytorium:

```sh
python3 -m http.server 8080 --bind 127.0.0.1 --directory hackathon-guide
```

Podgląd: http://127.0.0.1:8080/. Można również otworzyć HTML bezpośrednio; dołączone CSS, JS i fonty są lokalne.

## Pozostałe materiały

- `hackathon-flow-solo/` — źródłowy prototyp flow uczestnika.
- `hackathon-flow/` — wcześniejszy wariant flow.
- `widehue/` — design system, strona główna i starter HTML/CSS/JS.
- `widehue.zip` — zachowane archiwum projektu Widehue.
- `documents/` — kontekst, przygotowania, przykładowy brief i scenariusz prowadzącego.
- `KONTEKST-HACKATHONU-AI-NATIVE-DESIGN-SYSTEM.md` i `NOTATKI_HACKATHON.md` — kontekst oraz notatki warsztatowe.

Szczegóły przewodnika i brakujące linki opisano w `hackathon-guide/README.md`. Kolejne decyzje wizualne zostały wdrożone w przewodniku; wcześniejsze prototypy służą jako materiał odniesienia.
